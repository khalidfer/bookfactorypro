# 📚 KDP Book Factory Pro

**All-in-One Desktop Publishing & Interior Creation Suite for Amazon KDP Publishers**

KDP Book Factory Pro is a professional Windows desktop studio built to streamline every stage of low-content, medium-content, and activity book publishing on Amazon KDP—from automated interior generation and 300 DPI print optimization to full-wrap cover design and strict preflight auditing.

---

## ✨ Key Features

- **🧩 Automated Interior & Puzzle Generators**
  - **Mixed Variety Puzzle Studio**: Combine Word Search, Sudoku, Mazes, Math Worksheets, Cryptograms, Nonograms, and Word Scrambles with unified solution keys.
  - **Coloring & Art Studios**: Mandala Art Studio, Bulk Coloring Book Studio, and Photo-to-Line-Art tools.
  - **Batch & CSV Automation**: Generate multi-page books and variable-data planners in seconds.
- **🖼️ 300 DPI Image Upscaler & Print Enhancer**
  - Upscale artwork (`2x` / `4x`) with crisp line-art cleanup and automatic `300 DPI` print metadata embedding.
- **📐 KDP Smart Trim, Bleed & Cover Studio**
  - Built-in support for standard Amazon KDP trim sizes, gutter/safe-margin guides, Facing-Pages spread view, and Paperback/Hardcover dual-edition synchronization.
- **✅ Advanced KDP Preflight & Export**
  - Live page-count, margin, and print-readiness checks before exporting print-ready PDF files.
- **🔒 Privacy-First & BYOK (Bring Your Own Key)**
  - Runs locally on Windows with offline RSA/HWID license verification and user-configurable API keys stored locally.

---

## 📥 Download & Installation

1. Go to the [**Releases**](https://github.com/khalidfer/bookfactorypro/releases/latest) page.
2. Under **Assets**, download **`KDPBookFactoryPro_Setup.exe`**.
3. Run the installer and follow the on-screen setup instructions.
4. Launch **KDP Book Factory Pro** and enter your License Key (or click **Send HWID Request** inside the activation window).

---

## 🖥️ System Requirements

- **OS**: Windows 10 or Windows 11 (64-bit)
- **RAM**: 4 GB minimum (8 GB recommended for large batch exports)
- **Storage**: 300 MB free disk space
