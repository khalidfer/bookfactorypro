Quick Start & Activation

Get up and running on Windows in less than two minutes.

1

Download & Install

Download KDPBookFactoryPro_Setup.exe from GitHub Releases and run the Windows installer.

2

Send Your HWID

Open the app, click Show next to your Hardware ID, and click Send HWID Request (or copy and email it) to receive your license key.

3

Add Your API Keys

Open Tools → Preferences to enter your own free Gemini & Pixabay API keys and default author name.
